# Guia Web de Arquitetura de Software

Projeto desenvolvido para a Unidade Curricular de Gestão de Projetos,
do curso Superior de Tecnologia em Análise e Desenvolvimento de Sistemas
do SENAI EAD.

## Integrantes

- Ana Luiza Ribeiro de Oliveira
- Mônica Nunes Junquetti

## Sobre o projeto

O projeto consiste em um guia web interativo sobre conceitos de
arquitetura de software e seus impactos na gestão de projetos.

Foram abordados três conceitos:

1. Monolith First
2. Micro Frontends
3. Presentation Domain Data Layering

## Fontes

Os conteúdos foram desenvolvidos a partir dos textos de Martin Fowler:

- Monolith First:
  https://martinfowler.com/bliki/MonolithFirst.html

- Micro Frontends:
  https://martinfowler.com/articles/micro-frontends.html

- Presentation Domain Data Layering:
  https://martinfowler.com/bliki/PresentationDomainDataLayering.html

## Uso de Inteligência Artificial

A equipe utilizou ferramentas de Inteligência Artificial como apoio
durante o desenvolvimento do projeto.

A IA foi utilizada principalmente para:

- auxiliar na estruturação do site;
- apoiar a elaboração do código HTML, CSS e JavaScript;
- sugerir organização visual e elementos de interação;
- auxiliar na revisão e organização das explicações.

O conteúdo foi conferido pela equipe com base nos posts originais
de Martin Fowler, sendo realizadas adaptações e revisões para adequação
à proposta da atividade.

A responsabilidade pela seleção, revisão e apresentação do conteúdo
é da equipe.
